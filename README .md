# HWHNewCharacterExt

[![Version](https://img.shields.io/badge/version-2.83-blue.svg)](https://github.com/Green-oGo/HWHNewCharacterExt/raw/refs/heads/main/HWHNewCharacterExt.user.js)
[![License](https://img.shields.io/badge/license-Copyright%20Green-green.svg)](LICENSE)
[![Language](https://img.shields.io/badge/lang-English%20%7C%20Russian-yellow.svg)](README.md)

**HWHNewCharacterExt** — это расширение для популярного скрипта [HeroWarsHelper](https://github.com/), предназначенное для автоматизации и упрощения выполнения заданий в событиях "Восхождение Нового Героя" (New Hero) и "Пробуждение Титана" (Titan Awakens) в игре Hero Wars.

> ⚠️ **Внимание:** Данный скрипт является **расширением** и требует обязательной установки и работы базового скрипта **HeroWarsHelper**.

## ✨ Возможности

- 🦸 **Автоматизация событий:** Выполнение заданий ивента "Новый Герой" и "Пробуждение Титана" (сбор героев, титанов, навыков тотемов и питомцев).
- ⚔️ **Прохождение глав:** Автоматическое прохождение доступных глав вторжения (Invasion), включая рейды и битвы с боссом.
- 👹 **Архидемон:** Подготовка и атака на Архидемона с выбором оптимальной команды, питомцев и эмблем.
- 💰 **Трата монет доблести:** Автоматический обмен монет доблести (Valor Coins) в магазине события для выполнения заданий.
- 🛡️ **Умное управление эмблемами:** Выбор нужных эмблем, автоматический реролл (обновление) при необходимости, обработка "Эмблемы Капитала".
- 🛠️ **Утилиты:** 
  - Получение списков ID героев и титанов (включая тех, которых нет в магазине).
  - Автоматическое скрытие надоедливых обучающих сообщений (tutorial messages).
- 🧠 **Оптимизация боев:** Встроенный механизм `NewCharacterWinFixBattle` для корректировки времени и условий победы в сложных боях.
- 🌍 **Мультиязычность:** Полная поддержка английского 🇬🇧 и русского 🇷🇺 языков.

## 📋 Требования

1. Браузер: Google Chrome, Firefox, Edge, Opera или любой другой современный браузер.
2. Менеджер пользовательских скриптов: [Tampermonkey](https://www.tampermonkey.net/), [Violentmonkey](https://violentmonkey.github.io/) или [Greasemonkey](https://www.greasespot.net/).
3. **Обязательно:** Установленный и активный базовый скрипт **[HeroWarsHelper](https://github.com/)** (версии 2.390 и выше).

## 🚀 Установка

1. Установите расширение для управления скриптами (например, **Tampermonkey**) в ваш браузер.
2. Убедитесь, что у вас установлен и работает скрипт **HeroWarsHelper**.
3. Перейдите по ссылке для установки:
   👉 **[Установить HWHNewCharacterExt](https://github.com/Green-oGo/HWHNewCharacterExt/raw/refs/heads/main/HWHNewCharacterExt.user.js)**
4. Нажмите кнопку **"Install" (Установить)** в открывшемся окне менеджера скриптов.

## 🎮 Использование

1. Откройте игру [Hero Wars](https://www.hero-wars.com/).
2. Дождитесь полной загрузки игры и инициализации скрипта HeroWarsHelper.
3. Откройте меню **HeroWarsHelper**.
4. Перейдите во вкладку **"Разное" (Others)**.
5. Нажмите на кнопку **"Новый персонаж" (New Character)**.
6. Выберите нужное действие в появившемся меню (например, "Выполнить задания", "Пройти главу", "Атаковать Архидемона" или "Потратить монеты доблести").
7. Следуйте подсказкам на экране для настройки команды и запуска процесса.

## ⚙️ Настройки и сохранение

Скрипт автоматически сохраняет ваши предпочтения в локальном хранилище браузера:
- Выбранные команды для глав и Архидемона.
- Предпочитаемые эмблемы и навыки тотемов.
- Выбранные главы для Архидемона.
